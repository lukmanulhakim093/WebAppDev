# WebAppDev

Bismillahirrahmanirrahim.
Assalamu'alaikum teman-teman semua. Pada repository ini saya mengajak teman-teman untuk bisa memanfaatkan git dan github sebagai media pembelajaran mata kuliah pengembangan aplikasi web.

Git adalah media untuk mengontrol versi file dan melakukan tracking (penelusuran) terhadap perubahan pada sebuah repository. Istilah repo mungkin masih baru bagi kalian, namun perlahan-lahan anda mulai mengerti kenapa git dan github sangat berguna dalam pengembangan sistem secara profesional.

Repository adalah folder kolaborasi dimana semua tim yang bekerja didalam sebuah proyek dapat memonitor, mengontrol, berkolaborasi, serta mengambil tugas sesuai porsi dengan membuat cabang-cabang repository baru agar tidak mengganggu cabang utama.

Bayangkan, sebuah repository adalah sebuah folder project utama yang dapat diduplikasi kedalam kedalam komputer anda. Lalu anda melakukan perubahan hanya pada komputer anda. Jika suatu saat porsi pekerjaan anda telah selesai. Anda dapat melakukan merger ke folder project utama. Begitupun dengan tim anda yang lain.

Pada repository WebAppDev terdapat 2 folder yaitu lms dan praktikum:

1. Folder lms digunakan untuk memuat pengembangan aplikasi Learning Management System (LMS) sebagai contoh kasus pada mata kuliah pengembangan aplikasi web.
2. Sedangkan folder praktikum memuat file-file praktikum atau contoh program untuk menjelaskan cara kerja dari teori pembelajaran disetiap pertemuan.
